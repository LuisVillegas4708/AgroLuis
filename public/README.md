# /public

Assets estáticos servidos directo desde `/`.

- `favicon.svg` — ícono provisional (hoja verde). Pendiente: reemplazar con ícono final del dueño.
- `pwa-192x192.png`, `pwa-512x512.png` — pendientes (los genera vite-plugin-pwa o se diseñan).
- `apple-touch-icon.png` — para "Agregar a pantalla de inicio" en iPhone (pendiente).
- `manifest.webmanifest` — lo genera vite-plugin-pwa automáticamente con la config de `vite.config.js`.
